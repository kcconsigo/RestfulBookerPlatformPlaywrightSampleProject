<h1>Playwright Java TestNG Project: Restful Booker Platform</h1>

<h3><br>This Automation Framework use to test the Web UI and API on Restful Booker Platform to let the end users to select the room and book their dates</br></h3>

<h4>Tech Stack used:</h4>

Playwright Java, Playwright CRX, Github Copilot and MCP AI

<h4>Design Pattern Techniques:</h4>

Page Object Model, Object Oriented Programming

<h4>DevOps Tools and Practices:<h4>

Github Actions workflow, Cron Job Scheduled run, GIT and GitKraken, Applying Commit and Pull Request Standards
